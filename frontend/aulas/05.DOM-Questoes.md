# Avaliação: Manipulação do DOM com JavaScript

### 12 Questões de Múltipla Escolha (5 alternativas cada)

---

## Questão 1

**O que significa DOM?**

- A) Document Order Model
- B) Digital Object Method
- C) Document Object Model ✅
- D) Data Output Machine
- E) Document Oriented Module

---

### ✅ Resposta correta: **C) Document Object Model**

**Rubrica:** O DOM (Document Object Model) é uma interface que representa a estrutura de um documento HTML como uma árvore de objetos. Cada elemento HTML é convertido em um nó (node) dessa árvore, permitindo que o JavaScript acesse, manipule e modifique o conteúdo, a estrutura e o estilo da página de forma dinâmica. As demais opções são siglas inventadas que não correspondem a nenhuma tecnologia web real.

---

## Questão 2

**Qual dos itens abaixo NÃO é um tipo de nó (node) do DOM?**

- A) Element Node
- B) Text Node
- C) Attribute Node
- D) Comment Node
- E) Style Node ✅

---

### ✅ Resposta correta: **E) Style Node**

**Rubrica:** Os tipos de nós do DOM são: Element Nodes (tags HTML), Text Nodes (texto dentro das tags), Attribute Nodes (atributos das tags) e Comment Nodes (comentários no HTML). "Style Node" não existe como tipo de nó no DOM. Os estilos são aplicados via Attribute Nodes ou pelo objeto `style` dos Element Nodes.

## Questão 3

**Qual método retorna APENAS UM elemento do DOM pelo seu ID?**

- A) `getElementsByClassName()`
- B) `querySelectorAll()`
- C) `getElementsByTagName()`
- D) `getElementById()` ✅
- E) `getElementsByName()`

---

### ✅ Resposta correta: **D) `getElementById()`**

**Rubrica:** O `getElementById()` retorna um único elemento cujo atributo `id` corresponde ao valor informado, pois IDs devem ser únicos na página. Já `getElementsByClassName()`, `getElementsByTagName()`, `querySelectorAll()` e `getElementsByName()` retornam uma coleção (HTMLCollection ou NodeList) de múltiplos elementos, pois classes, tags, seletores CSS e nomes podem se repetir.

---

## Questão 4

**Qual método permite selecionar elementos usando qualquer seletor CSS (como `.classe`, `#id`, `tag > filho`)?**

- A) `getElementById()`
- B) `getElementsByTagName()`
- C) `querySelector()` ✅
- D) `getElementsByName()`
- E) `getElement()`

---

### ✅ Resposta correta: **C) `querySelector()`**

**Rubrica:** O `querySelector()` aceita qualquer seletor CSS válido e retorna o **primeiro** elemento que corresponde ao seletor. Para retornar **todos** os elementos correspondentes, utiliza-se `querySelectorAll()`. Os demais métodos aceitam apenas parâmetros específicos (ID, nome da tag ou atributo `name`). `getElement()` (opção E) sequer existe como método nativo do DOM.

## Questão 5

**Qual propriedade permite alterar o conteúdo HTML interno de um elemento, interpretando tags HTML?**

- A) `textContent`
- B) `innerText`
- C) `nodeValue`
- D) `outerHTML`
- E) `innerHTML` ✅

---

### ✅ Resposta correta: **E) `innerHTML`**

**Rubrica:** A propriedade `innerHTML` define ou retorna o conteúdo HTML dentro de um elemento, interpretando as tags. Por exemplo, `elemento.innerHTML = '<strong>Negrito</strong>'` renderiza o texto em negrito. `textContent` e `innerText` retornam apenas o texto puro sem interpretar tags. `nodeValue` retorna o valor do nó (geralmente texto puro). `outerHTML` inclui o próprio elemento e todo o seu conteúdo.

## Questão 6

**Qual é a ordem correta para adicionar um novo elemento ao DOM?**

- A) `appendChild()` → `createElement()` → `textContent`
- B) `textContent` → `appendChild()` → `createElement()`
- C) `appendChild()` → `textContent` → `createElement()`
- D) `createElement()` → `textContent` → `appendChild()` ✅
- E) `createElement()` → `appendChild()` → `textContent`

---

### ✅ Resposta correta: **D) `createElement()` → `textContent` → `appendChild()`**

**Rubrica:** Primeiro cria-se o elemento com `document.createElement('p')`, depois define-se o conteúdo com `textContent` (ou `innerHTML`), e por fim insere-se o elemento no DOM com `appendChild()`. Não faz sentido adicionar um elemento que ainda não foi criado (opções A e C), nem definir texto antes de criar o elemento (opção B), nem adicionar ao DOM antes de definir o conteúdo (opção E).

---

## Questão 7

**Qual método NÃO é utilizado para manipular atributos de um elemento HTML?**

- A) `getAttribute()`
- B) `setAttribute()`
- C) `removeAttribute()`
- D) `classList.add()` ✅
- E) `hasAttribute()`

---

### ✅ Resposta correta: **D) `classList.add()`**

**Rubrica:** `getAttribute()`, `setAttribute()`, `removeAttribute()` e `hasAttribute()` são métodos específicos para manipular **atributos** HTML (como `src`, `alt`, `href`, `title`). O `classList.add()` é um método da propriedade `classList` que manipula exclusivamente **classes CSS** do elemento. Embora `class` seja um atributo HTML, o `classList` é uma API dedicada ao gerenciamento de classes e não é considerado um método genérico de manipulação de atributos.

---

## Questão 8

**Qual método da propriedade `classList` permite alternar (adicionar/remover) uma classe?**

- A) `classList.add()`
- B) `classList.remove()`
- C) `classList.contains()`
- D) `classList.replace()`
- E) `classList.toggle()` ✅

---

### ✅ Resposta correta: **E) `classList.toggle()`**

**Rubrica:** O `toggle()` verifica se a classe existe no elemento. Se existir, remove; se não existir, adiciona. É ideal para criar alternâncias de estado, como menus abertos/fechados ou temas claro/escuro. O `add()` apenas adiciona, o `remove()` apenas remove, o `contains()` apenas verifica se a classe existe (retorna booleano), e o `replace()` substitui uma classe por outra.

## Questão 9

**Qual é a forma correta de adicionar um evento de clique a um botão?**

- A) `button.onClick = 'alert("Clicado!")'`
- B) `button.clickEvent('alert("Clicado!")')`
- C) `button.on('click', alert('Clicado!'))`
- D) `button.trigger('click', function() { alert('Clicado!') })`
- E) `button.addEventListener('click', () => { alert('Clicado!') })` ✅

---

### ✅ Resposta correta: **E) `button.addEventListener('click', () => { alert('Clicado!') })`**

**Rubrica:** O `addEventListener()` é o método padrão para registrar eventos no DOM. Ele recebe o nome do evento (`'click'`) como primeiro argumento e uma função callback como segundo. A opção A (`onClick`) aceita apenas uma string, não uma função. As opções B, C e D não existem como métodos válidos do DOM nativo.

## Questão 10

**Dado o HTML abaixo, qual é o tipo do nó que contém `"world!"`?**

```html
<p>Hello, <strong>world!</strong></p>
```

- A) Element Node
- B) Attribute Node
- C) Comment Node
- D) Text Node ✅
- E) Document Node

---

### ✅ Resposta correta: **D) Text Node**

**Rubrica:** O texto `"world!"` dentro do `<strong>` é um **Text Node** (nó de texto). A tag `<strong>` em si é um **Element Node**. Se houvesse um atributo como `class="frase"`, ele seria um **Attribute Node**. Comentários HTML (`<!-- -->`) seriam **Comment Nodes**. Document Nodes representam o documento inteiro, não trechos de texto.

## Questão 11

**Qual propriedade é mais segura para inserir texto em um elemento, evitando ataques de XSS (Cross-Site Scripting)?**

- A) `innerHTML`
- B) `outerHTML`
- C) `insertAdjacentHTML()`
- D) `textContent` ✅
- E) `document.write()`

---

### ✅ Resposta correta: **D) `textContent`**

**Rubrica:** A propriedade `textContent` insere o valor como texto puro, sem interpretar tags HTML. Isso impede que código malicioso (como `<script>alert('XSS')</script>`) seja executado. Já `innerHTML`, `outerHTML`, `insertAdjacentHTML()` e `document.write()` interpretam e executam o HTML inserido, o que pode abrir brechas de segurança se o conteúdo não for sanitizado.

## Questão 12

**Qual é a função do método `removeChild()` no DOM?**

- A) Criar um novo elemento filho
- B) Substituir um elemento filho por outro
- C) Clonar um elemento filho
- D) Inserir um elemento antes de outro
- E) Remover um elemento filho de um elemento pai ✅

---

### ✅ Resposta correta: **E) Remover um elemento filho de um elemento pai**

**Rubrica:** O `removeChild()` remove um nó filho específico de dentro de seu nó pai. É necessário ter uma referência tanto ao pai quanto ao filho: `pai.removeChild(filho)`. Para criar elementos usa-se `createElement()` (opção A), para substituir usa-se `replaceChild()` (opção B), para clonar usa-se `cloneNode()` (opção C), e para inserir antes de outro usa-se `insertBefore()` (opção D).
